✨ Core Features

📝 Item Reporting

Users can report lost or found items with detailed information including name, description, category, location, date, and optional image uploads.

🔍 Smart Search

Advanced search and filtering by keyword, category, location, and date range to help users quickly find items.

🛡️ Secure Claims

Verified ownership process where users can claim found items and admins verify authenticity before approval.

👨‍💼 Admin Dashboard

Comprehensive admin panel for managing claims, approving items, and overseeing all lost and found activities.

📸 Cloud Storage

Secure S3 cloud storage for item photos with automatic optimization and reliable retrieval.

🔔 Notifications

Automated owner notifications for new items, claims, and status updates to enable quick response times.
